## webpack テンプレート

JSのバンドルのみに機能を絞った最小限のWebpackテンプレートです。
プロジェクトメンバー全員がWebpackをインストールする必要はなく、JSのバンドルが必要なメンバーのみインストールし作業を行うことが可能です。

```bash
▼git
https://gpinternal.backlog.jp/git/CODING_TEMPLATE/webpack-template.git

            
▼Operation confirmed environment
【Node.js Version】
Node.js　v20.17.0 以上
【npm Version】
npm　10.8.2 以上
```

[webpackテンプレートについて詳しくはこちら](./webpack/)
